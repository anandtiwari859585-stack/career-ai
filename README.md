# 🎓 CareerAI — Student Career Guidance

> An AI-powered, fully client-side career guidance web app that helps students and fresh graduates discover their ideal career path through a smart quiz, GitHub analysis, skill assessment, and a personalised roadmap.

**Live Demo:** [https://anandtiwari859585-stack.github.io/career-ai/career-guide/](https://anandtiwari859585-stack.github.io/career-ai/career-guide/)

---

## ✨ Features

| Feature | Description |
|---|---|
| 🧠 **Smart Quiz** | 10 scenario-based questions that reveal your true interests and working style |
| 💻 **GitHub Analysis** | Fetches your public repositories via GitHub API to understand your technical depth |
| 👤 **Profile Builder** | Captures your academic background, region, and CGPA for personalised results |
| 🛠️ **Skills Assessment** | Select from 50+ languages, frameworks, and tools to refine your match |
| 🎯 **Career Preferences** | Work environment, job priorities, and dream company type |
| 🗺️ **Personalised Roadmap** | 3-phase step-by-step career roadmap with interactive checkboxes |
| ✅ **Roadmap Questions** | Tick any roadmap item to get a contextual question + instant personalised tip |
| 💰 **Salary Insights** | Entry, mid, senior, and leadership salary ranges for India & US/Global |
| 📈 **Career Growth Score** | Industry demand and growth percentage for your matched career |
| ⚖️ **Work-Life Balance** | Scores for stress, flexibility, remote options, and job satisfaction |
| 🏅 **Promotion Track** | Full promotion ladder with typical years at each level |
| 🔀 **Alternative Paths** | 3 alternative careers with skill overlap percentage |
| 🚀 **Motivational Quote** | A career-specific quote to keep you inspired |
| 🖨️ **Save / Print** | Print or save your full results as a PDF |

## 🛠️ Running Locally

No installation needed. Just open the file in your browser:

```bash
# Clone the repo
git clone https://github.com/anandtiwari859585-stack/career-ai.git

# Open in browser
cd career-ai/career-guide
# Double-click index.html  OR  run a local server:
npx serve .
```

Or simply open:
```
career-guide/index.html
```

---

## 🗺️ Interactive Roadmap

Each roadmap item has a **checkbox**. Tick it to:
1. See a contextual question about your current level on that topic
2. Pick one of 4 options
3. Get an instant **personalised tip** on what to do next

Questions cover 20+ roadmap items across all career paths — DSA, system design, Kubernetes, LLMs, Figma, bug bounty, and more.
